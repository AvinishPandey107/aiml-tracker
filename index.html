Frequently Asked Questions

How is my Level and XP calculated?
Every resource watched or read grants 10 XP. Completing an entire topic grants 50 XP, and building a project grants 100 XP. As your XP grows, your rank advances from Level 1 (Curious Beginner) up to Level 10 (Global AI/ML Master).
Why does OAuth fail when opening as a local file (file:///)?
OAuth security standards (RFC 6749) forbid redirects to file:/// URLs. To use Google, GitHub, or Discord login, serve the folder using VS Code Live Server (http://127.0.0.1:5500), Python's python -m http.server, or deploy for free on GitHub Pages / Vercel.
How do College and Country Rankings work?
Click [👤 Profile] in the top-right controls to set your College/University and Country. Once set, your profile and XP will be factored into the respective College and Country leaderboards alongside global peers!
Can I use my own Google Gemini API Key for the AI Copilot?
Yes! The AI Copilot includes a built-in offline ML reasoning engine that works without any keys. However, you can also paste your Google Gemini API key into the Copilot settings drawer to enable live, state-of-the-art LLM streaming for arbitrary questions.
How do I change or reset my password?
If you are already logged in, click [👤 Profile] in the top right and use the "Change Password" form. If you are logged out, click "Forgot Password" on the sign-in screen to receive a secure reset link.
